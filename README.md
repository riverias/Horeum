# 🎧 Horeum

**Horeum** — десктопный музыкальный плеер нового поколения на **Tauri v2 + Rust + React 18 + TypeScript**.
Поиск и стриминг реальных треков из SoundCloud, синхронизированный текст песен, «Волна» (бесконечное персональное радио),
подборки по настроению, плейлисты, профиль с уровнями, XP, ачивками, рамками и фонами.

---

## ✨ Возможности

### Музыка
- 🔎 **Реальный поиск треков** через SoundCloud API v2 (авто-добыча `client_id`, авто-обновление при 401)
- ▶️ Воспроизведение **progressive (mp3)** и **HLS (m3u8)** транскодингов (hls.js)
- 📈 Чарты SoundCloud (Top / Trending) по 20+ жанрам
- 🌊 **Волна** — бесконечное радио: seed-треки из лайков/истории + related + жанровая подмешка + фильтры по энергии
- 🎭 **Настроения** — 12 моделей настроения (Chill, Euphoria, Rage, Melancholy, Focus, Night Drive…) с генерацией очереди
- 📃 **Плейлисты** — создание, редактирование, обложки, drag-n-drop сортировка, импорт плейлистов SoundCloud по ссылке
- ❤️ Лайки, история прослушиваний, «Слушать позже», умные автоплейлисты
- 🔁 Repeat (off/all/one), 🔀 Shuffle (Fisher–Yates), очередь с приоритетом (Play next)
- ⏱️ Кроссфейд, нормализация громкости, скорость воспроизведения, sleep-timer
- 🎚️ **10-полосный эквалайзер** + пресеты + Bass boost + Reverb (Web Audio API)
- 📊 Визуализатор (bars / wave / radial) на AnalyserNode
- 🖼️ Динамическая тема из обложки трека (извлечение доминантных цветов)

### Текст песен
- 🎤 **Синхронизированные тексты** (LRC) из [LRCLIB](https://lrclib.net) — автоскролл, караоке-подсветка строки
- 📝 Fallback на простой текст, ручной поиск, кэш в SQLite

### Аккаунт SoundCloud
- 🔐 Вход по OAuth-токену вашего аккаунта → доступ к своим лайкам, плейлистам, подпискам
- ⬆️ Синхронизация лайков в локальную библиотеку

### Профиль и геймификация
- 👤 Профиль: ник, био, аватар, баннер
- 🧬 **Уровни и XP** — XP за прослушивания, лайки, открытия новых артистов, серии дней
- 🖼️ **Кастомизация**: 12 фонов (в т.ч. анимированные градиенты/aurora/mesh), 10 рамок аватара, 8 акцентных тем
- 🏆 Ачивки/бейджи, статистика: топ-артисты, топ-жанры, минуты прослушивания, стрик

### UI/UX
- 🪟 Кастомный безрамочный titlebar, acrylic/blur, плавные анимации Framer Motion
- ⌨️ Горячие клавиши, командная палитра (Ctrl+K), контекстные меню, тосты, скелетоны
- 🧩 Radix UI primitives + TailwindCSS + Lucide иконки

## 🚀 Запуск

```bash
# 1. зависимости
npm install

# 2. иконки (один раз, нужен любой png 1024x1024)
npm run tauri icon ./app-icon.png

# 3. dev
npm run tauri dev

# 4. сборка
npm run tauri build
```

Требования: Node 18+, Rust 1.77+, системные зависимости Tauri v2 (WebView2 на Windows, `webkit2gtk-4.1` на Linux).

## 🔑 Вход в SoundCloud (опционально)

1. Откройте soundcloud.com в браузере и войдите.
2. DevTools → Application → Cookies → `oauth_token` (значение вида `2-2xxxxx-...`).
3. В Horeum: **Профиль → Подключить SoundCloud → вставить токен**.

Токен хранится **локально** в SQLite (`horeum.db`) и уходит только на `api-v2.soundcloud.com`.

## 📁 Структура

```
src-tauri/src
  ├─ soundcloud.rs   # client_id, поиск, чарты, related, stream URL, аккаунт
  ├─ lyrics.rs       # LRCLIB, парсер LRC, кэш
  ├─ db.rs           # SQLite: плейлисты, лайки, история, профиль, настройки
  ├─ profile.rs      # XP, уровни, ачивки, разблокировки
  ├─ wave.rs         # алгоритм «Волны» и настроений
  └─ commands.rs     # Tauri-команды (мост к фронтенду)
src
  ├─ store/          # Zustand-сторы
  ├─ audio/          # аудиодвижок, эквалайзер, визуализатор
  ├─ components/     # UI
  └─ views/          # экраны
```

## ⚖️ Дисклеймер

Проект использует публичный SoundCloud API v2 в образовательных целях. Соблюдайте условия использования SoundCloud;
не распространяйте загруженный контент. Тексты песен предоставляются LRCLIB.
